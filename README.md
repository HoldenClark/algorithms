# algorithms
repo where I store all of my leetcode/hackerrank dsa/algorithms study/prep/etc. related files and notes and etc.


### RUNNING Python FILES
1. ensure your system has python installed with either "python3 --version" or "python --version", you should see a version number if installed correctly
2. navigate to the directory that has the desired python file you want to run
   example: I want to run "binary_search.py", so I make sure my current working directory is "~/algorithms/neetcode150"
3. run command "python3 <desired-file-to-run>"
4. view the output in your terminal

### RUNNING C++ FILES
1. ensure you have a compiler for C++ programs on your system
   example: run in your terminal "g++ --version" and you should see a version number and date
   note: you can use other compilers, but these instructions are for g++
2. check that file you want to run ends with ".cpp"
3. navigate to directory that has desired C++ file you want compile
   example: I want to run "~/algorithms/neetcode150/daily_temperatures.cpp", make sure your current working directory is "~/algorithms/neetcode150"
4. run command "g++ <file-name> -o <desired-output-name>"
   example: "g++ daily_temperatures.cpp -o test"
5. run the compiled executable, with command "./<desired-output-name>"
   example: "./test"
6. view the output in your terminal
